# EEG 代码学习台

一个本地优先的 30 天 EEG 代码接手训练系统。网站记录计划、证据、代码地图、实验和周复盘；计划调整只生成建议，接受后才会修改下一任务。

## 启动

```powershell
cd C:\Users\ZhuanZ\Desktop\世界模型\eeg-learning-system
npm start
```

打开 `http://127.0.0.1:4312`。

GitHub Pages 部署时会自动切换为浏览器本地存储，手机上的进度只保存在手机浏览器中，不上传到仓库。

## 数据

- 主状态：`data/state.json`
- 快照：`data/backups/`
- 页面右上角可以导出 JSON

## 任务规则

- 每天只有一个核心成果。
- 根据可用时间选择最低、标准或扩展完成。
- “完成并验收”必须填写成果证据。
- 部分完成、阻塞或跳过时，系统只提出调整建议。
- 后续计划只有在用户接受建议后才会改变。
