# 游戏脑电情绪学习台

30 天训练：情绪标签与脑电处理、频带特征和 EEGNet、可信评估、游戏连续回放。

在线网站：https://yuegu7800.github.io/eeg-code-learning-system/

运行：Node.js 22+，执行 npm start，访问 http://127.0.0.1:4312 。

旧课程会保存到 curriculumHistory；第1天环境任务保留进度，变更的任务重新学习。已有实验、代码地图和开始日期保留。

本地数据存于 data/state.json；线上数据仅存当前浏览器，两者不自动同步。Codex 提醒读取电脑数据；网站中的提醒时间是记录值，不会自动改变调度。

没有真实获准数据时用合成信号验证接口，不能报告情绪识别效果。DEAP 是非游戏教学候选，其结果不能直接代表游戏表现。

测试：npm test。
